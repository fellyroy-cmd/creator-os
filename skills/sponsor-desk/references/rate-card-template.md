# Rate card template

Copy this to `creator/rate-card.md` and fill in your own numbers. The sponsor-desk skill reads **only**
this file for prices — it never invents a number, and it never uses someone else's rates. If a field below
doesn't apply to you, delete it rather than leaving a placeholder in.

Keep it as **list price** (what you ask for first) and **floor** (the lowest you'll actually accept before
you want to be asked, not told). The gap between them is your real negotiating room.
